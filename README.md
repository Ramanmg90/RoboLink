# RoboLink | کنترل هوشمند برق

اپلیکیشن اندروید (Flutter) برای کنترل یک رله‌ی تک‌کاناله روی **Wemos D1 mini (ESP8266)** از طریق وای‌فای محلی، با رابط فارسی راست‌به‌چپ و طراحی Neon Glassmorphism.

> **وضعیت راستی‌آزمایی (مهم):** این پروژه در محیطی نوشته شد که Flutter/Dart SDK در آن نصب نبود. بنابراین
> `flutter analyze`، `flutter test` و `flutter build apk` **هنوز اجرا نشده‌اند** و هیچ ادعایی دربارهٔ موفقیت آن‌ها نمی‌شود.
> فقط بررسی ساده‌ی ساختار (تعادل پرانتزها و صحت مسیر importها) و اجرای اسکریپت patch منیفست انجام شده است.
> قدم اول شما اجرای دستورهای بخش «راه‌اندازی» است؛ اگر خطای کامپایل دیدید، متن خطا را بفرستید تا اصلاح شود.

## وضعیت فعلی: حالت دمو
چون هنوز برد ندارید، برنامه در اولین اجرا با یک دستگاه **شبیه‌سازی‌شده** («چراغ اتاق») شروع می‌شود:
- هیچ فرمانی به شبکه ارسال نمی‌شود و همه‌جا برچسب «شبیه‌سازی‌شده» دارد.
- در پنل شبیه‌ساز (صفحه‌ی خانه) می‌توانید «قطع ارتباط» (وضعیت نامشخص) و «خطا در فرمان بعدی» را امتحان کنید.
- لایه‌ی ارتباط واقعی HTTP و فریمور کامل هستند؛ وقتی برد رسید فقط یک دستگاه واقعی اضافه کنید (دستگاه‌ها ← افزودن).

## ویژگی‌ها
- صفحه‌ها: خانه، کنترل دستگاه، دستگاه‌ها، افزودن/ویرایش (ویزارد اتصال)، تنظیمات، تاریخچه.
- کلید برق با پنج حالت: روشن، خاموش، در حال ارسال، خطا، **نامشخص** (نامشخص ≠ خاموش).
- موفقیت فرمان فقط پس از تأیید دستگاه گزارش می‌شود؛ فرمان همزمان رد می‌شود.
- اگر دستگاه در دسترس نباشد وضعیت رله «نامشخص» می‌شود (وضعیت قدیمی نمایش داده نمی‌شود).
- تاریخچه‌ی محلی: «فرمان ارسال شد» و «فرمان تأیید شد» جدا ثبت می‌شوند؛ فقط رویدادهایی که برنامه دیده است.
- تنظیمات ماندگار: پوسته، مهلت درخواست (۲ تا ۱۵ ثانیه)، بازخوانی خودکار (۱۰ ثانیه)، لرزش، بازگردانی پیش‌فرض.
- بازخوانی خودکار هنگام بازگشت به برنامه (مثلاً بعد از عوض شدن وای‌فای).

## پیش‌نیازها
Flutter ‎≥ 3.22 (Dart ‎≥ 3.4)، Android SDK، Python 3 (فقط برای اسکریپت patch منیفست).
وابستگی‌ها: `flutter_riverpod`، `go_router`، `http` (و `flutter_localizations`). هیچ پلاگین بومی (native) استفاده نمی‌شود. فونت Vazirmatn داخل `assets/fonts` همراه پروژه است (مجوز OFL).

## راه‌اندازی
```bash
cd robolink
./tool/setup.sh          # ساخت پوشه android + مجوز اینترنت + HTTP محلی + flutter pub get
flutter analyze
flutter test
flutter run              # با گوشی یا امولاتور
```
اگر `setup.sh` اجرا نمی‌شود: `flutter create --platforms=android --org ir.roboram --project-name robolink .` سپس `python3 tool/patch_android.py`.

## ساخت APK
```bash
flutter build apk --release --no-shrink
# خروجی: build/app/outputs/flutter-apk/app-release.apk
```
برای انتشار عمومی باید کلید امضای اختصاصی تنظیم کنید (راهنمای رسمی Flutter: Build and release an Android app).

## ساختار پروژه
```
lib/app/            مسیریابی، پوسته (app_colors, glass_theme, app_theme)
lib/core/           ویجت‌های شیشه‌ای مشترک، ذخیره‌سازی، خطاها، ابزارها
lib/data/           مدل‌ها و سرویس‌های ارتباطی (HTTP واقعی + دمو)
lib/features/       device_control (کنترلر وضعیت)، home، devices، connection، history، settings
firmware/           فریمور ESP8266
docs/API.md         مستند API
test/               تست‌های مدل، ارتباط HTTP و منطق کنترلر
```
کد شبکه (`HttpDeviceGateway`) از UI جداست و پشت `DeviceGateway` قرار دارد؛ افزودن چند دستگاه یا زمان‌بندی بدون بازنویسی ممکن است (مدل `ScheduleRule` آماده است ولی فعلاً به UI وصل نیست).

## API
جزئیات و نمونه‌ی `curl` در [docs/API.md](docs/API.md): `GET /api/status` و `POST /api/relay`.

## فریمور و سخت‌افزار
1. در Arduino IDE بردهای ESP8266 را نصب کنید و برد **LOLIN(WEMOS) D1 R2 & mini** را انتخاب کنید (کتابخانه‌ی اضافه لازم نیست).
2. `firmware/robolink_firmware/secrets.example.h` را به `secrets.h` کپی و SSID/رمز وای‌فای (و در صورت نیاز `AUTH_TOKEN`) را وارد کنید.
3. در `config.h` فقط در صورت نیاز `RELAY_PIN` و `RELAY_ACTIVE_LOW` را تغییر دهید.
4. آپلود کنید، Serial Monitor را با ۱۱۵۲۰۰ باز کنید؛ آدرس IP چاپ می‌شود. همان را در برنامه وارد کنید.

| پین رله | مقدار پیش‌فرض |
|---|---|
| سیگنال رله (IN) | D1 (GPIO5) |
| تغذیه ماژول | 5V و GND (طبق دیتاشیت ماژول) |
| منطق رله | active-HIGH (برای ماژول‌های active-LOW مقدار `RELAY_ACTIVE_LOW` را 1 کنید) |

شروع امن: خروجی قبل از فعال شدن پین روی حالت خاموش تنظیم می‌شود و آخرین وضعیت هرگز بازیابی نمی‌شود (`RELAY_INITIAL_STATE_ON 0`).
پین‌های D3/D4/D8 را برای رله استفاده نکنید (روی بوت اثر دارند).

## ایمنی و امنیت
- ابتدا با **بار کم‌ولتاژ** (مثلاً LED با مقاومت یا بار ۵ تا ۱۲ ولت) تست کنید.
- مشخصات تماس رله را (ولتاژ/جریان مجاز) از دیتاشیت بخوانید و از آن بیشتر بار نگذارید؛ ماژول‌های ارزان معمولاً برای بار القایی/موتور مناسب نیستند.
- کار با برق شهر فقط با عایق‌بندی، محفظه‌ی مناسب، فیوز و نظارت فرد بزرگسال و مجرب.
- دستگاه را مستقیم روی اینترنت قرار ندهید و هرگز پورت روتر را باز نکنید. کنترل فقط وقتی کار می‌کند که گوشی و دستگاه به یک شبکه وصل باشند.
- توکن دسترسی (اختیاری) در `secrets.h` فریمور و در برنامه تنظیم می‌شود؛ هیچ مقدار پیش‌فرضی در کد وجود ندارد.

## محدودیت‌های شناخته‌شده
- کد کامپایل و تست نشده است (بالا را ببینید).
- فقط فارسی؛ انگلیسی در تنظیمات «به‌زودی» است.
- زمان‌بندی پیاده‌سازی نشده است (فقط مدل داده و کارت «در نسخه‌های بعدی»).
- در نسخه‌ی ۱ فقط دستگاه فعال پایش می‌شود؛ بقیه «پایش نمی‌شوند».
- داده‌ها (از جمله توکن) در یک فایل JSON در حافظه‌ی خصوصی برنامه به‌صورت متن ساده ذخیره می‌شوند (نه Keystore). مسیر ذخیره‌سازی برای اندروید روی نام بسته‌ی `ir.roboram.robolink` ثابت شده است.
- HTTP بدون رمزنگاری است و برای دسترسی به ESP8266 در شبکه‌ی محلی `usesCleartextTraffic` فعال می‌شود.
- کشف خودکار دستگاه ندارد؛ آدرس باید دستی وارد شود. `robolink.local` روی برخی نسخه‌های اندروید کار نمی‌کند؛ از IP استفاده کنید.

## ساخت APK با GitHub Actions
فایل `.github/workflows/build-apk.yml` با هر push روی شاخه‌ی `main` (یا اجرای دستی از تب Actions) پروژه را می‌سازد و فایل `app-release.apk` را به‌عنوان Artifact با نام `robolink-apk` ذخیره می‌کند. نیازی به نصب Flutter روی سیستم خودتان نیست.
